# Instruções do repositório

Leia integralmente `AGENT.md` antes de trabalhar neste projeto. Ele contém o contexto funcional e as diretrizes solicitadas pelo usuário. Consulte também `docs/SPEC_ARQUITETURA.md` para arquitetura, propostas técnicas, pendências e sequência de implementação. O backend está em `api`. A solicitação mais recente autorizou criar um esqueleto React JS em `web`, com visual simples, aguardando referência de design. Preservar o padrão de espaçamento e legibilidade solicitado pelo usuário. Leia `docs/STATUS_BACKEND.md` para o estado e as políticas pendentes do backend e `docs/STATUS_FRONTEND.md` para o frontend.
